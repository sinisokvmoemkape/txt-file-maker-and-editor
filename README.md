# txt-file-maker-and-editor
Небольшая учебная программа на Python: спрашивает имя текстового файла, затем количество строк и записывает введённый текст в файл с расширением `.txt` внутри папки `your_files`.

## Как запустить

1. Установите Python 3.
2. Создайте рядом со скриптом папку `your_files`.
3. Запустите скрипт командой:

   ```bash
   python txt-fa.py
   ```

4. Введите имя файла, количество строк и сами строки.

## Текущее состояние

Это первая учебная версия. Сейчас повторный запуск создания файла с тем же именем очищает его содержимое. Вопрос «создать ещё файл?» пока не завершает программу: условие выхода ещё нужно реализовать.
